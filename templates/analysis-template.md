# 平台博主分析报告 · 标准化执行模板

> 版本：v1.0
> 创建日期：2026-04-29
> 适用范围：B站、抖音、小红书、YouTube、公众号等任意平台的博主/创作者分析
> 用途：固化分析框架和视觉风格规范，确保跨平台报告一致性

---

## 一、分析框架

### 1.1 数据采集维度

对每位博主，需采集以下字段：

| 字段 | 说明 | 数据来源 |
|------|------|----------|
| `rank` | 综合排名 | 榜单排名 + 自定义评分 |
| `name` | 博主名称 | 平台主页 |
| `fans` | 粉丝数（万） | 平台公开数据 |
| `category` | 内容类别 | 内容分析归类 |
| `tags` | 内容标签（3-5个） | 视频内容分析 |
| `style` | 风格流派名称 | 定性分析 |
| `styleDesc` | 风格详细描述（50-100字） | 内容分析 |
| `monetization` | 盈利模式列表（含权重%） | 公开信息+行业推断 |
| `influence.breadth` | 平台覆盖广度 | 多平台检索 |
| `influence.depth` | 行业影响深度 | 行业报告+定性评估 |
| `influence.engagement` | 用户互动特征 | 弹幕/评论/点赞数据 |
| `videos` | 累计视频数 | 平台公开数据 |
| `avgPlay` | 平均播放量（万） | 计算得出 |
| `platform` | 平台分布 | 多平台检索 |
| `source` | 数据来源标注 | 采集时记录 |

### 1.2 排名方法论

综合排名 = 加权评分，权重建议：

| 维度 | 权重 | 说明 |
|------|------|------|
| 粉丝规模 | 25% | 直接反映影响力基数 |
| 内容质量 | 25% | 完播率、互动率、内容深度 |
| 行业影响力 | 20% | 榜单排名、行业认可度、媒体引用 |
| 更新活跃度 | 15% | 更新频率、内容持续性 |
| 商业价值 | 15% | 变现能力、品牌合作级别 |

### 1.3 分析报告结构（5大板块）

```
01. 数据总览
    - 核心指标统计卡片（总粉丝、人均粉丝、总视频数、类别数）
    - 内容类别分布（环形图）
    - 盈利模式分布（横向条形图）

02. 多维排名
    - 粉丝规模排名（横向条形图 TOP 10）
    - 平均播放量排名（横向条形图 TOP 10）
    - 视频产出量排名（横向条形图 TOP 10）

03. 盈利模式分析（深化版）
    - 变现方式采用频次统计
    - 六大变现路径详解（品牌商单/知识付费/企业服务/平台激励/分销佣金/多元衍生）
    - 收入层级估算（头部/中头部/中腰部/成长型）

04. 内容风格画像
    - 风格流派分类（10大流派）
    - 每个流派：名称、代表博主、特征描述

05. 影响力评估
    - 三维评估：覆盖广度 × 影响深度 × 互动质量
    - 影响力矩阵散点图（广度 vs 深度）
    - 各维度 TOP 5 排名

附：博主详情卡片（可展开）
    - 完整画像信息
    - 盈利结构明细
    - 风格描述
    - 影响力三维评估

附：数据来源与免责声明
```

## 二、视觉风格规范

### 2.1 设计系统

| 属性 | 值 |
|------|-----|
| 背景色 | `#0a0a0f`（主背景）、`#111118`（卡片背景）、`#0d0d14`（嵌套背景） |
| 边框色 | `#1a1a25`（默认）、`#00d4aa40`（激活态） |
| 主文字 | `#e0e0e0` |
| 次文字 | `#888` |
| 弱文字 | `#555` |
| 极弱文字 | `#333` / `#444` |
| 强调色 | `#00d4aa`（品牌绿） |
| 字体-正文 | `'Noto Sans SC', sans-serif` |
| 字体-数据 | `'JetBrains Mono', monospace` |
| 字体-衬线 | `'Noto Serif SC', serif`（备用） |
| 圆角 | `12px`（卡片）、`8px`（嵌套）、`4px`（标签） |
| 间距基准 | `40px`（页面边距）、`24px`（卡片内距）、`20px`（卡片间距） |

### 2.3 组件规范

#### 导航栏
- `position: sticky; top: 0; z-index: 100`
- 背景：`rgba(10,10,15,0.92)` + `backdrop-filter: blur(12px)`
- 激活态：`color: #00d4aa` + `border-bottom: 2px solid #00d4aa`
- 字号：`12px`，字重：`500`

#### 章节标题
- 编号标签：`font-family: JetBrains Mono`，`10-11px`，`color: #00d4aa`，带边框背景
- 标题：`20px`，`font-weight: 700`，`color: #fff`
- 副标题：`12px`，`color: #555`，左边距对齐内容

#### 数据卡片
- 背景：`#111118`
- 边框：`1px solid #1a1a25`
- 圆角：`12px`
- 内距：`24px`（默认）/ `20px`（紧凑）/ `18px`（更紧凑）

#### 横向条形图
- 标签宽度：`90-120px`，右对齐
- 条形高度：`14-22px`
- 背景：`rgba(255,255,255,0.03)`
- 动画：`transition: width 0.8s cubic-bezier(0.16, 1, 0.3, 1)`

#### 标签（Tag）
- 圆角：`12px`
- 字号：`11px`
- 背景：`{color}12`（8%透明度）
- 边框：`1px solid {color}25`

#### 博主详情卡片
- 默认折叠，点击展开
- 头像区：`40-48px` 圆角方块，渐变背景 + 博主首字母
- 展开动画：`fadeUp 0.3s ease`

### 2.4 动画

```css
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(12px); }
  to { opacity: 1; transform: translateY(0); }
}
```

### 2.5 技术栈

- React 18.3.1（pinned + integrity hash）
- ReactDOM 18.3.1（pinned + integrity hash）
- Babel 7.29.0（pinned + integrity hash）
- Google Fonts: Noto Sans SC + JetBrains Mono
- 单文件 inline React（所有 JSX 内联，双击即可打开）

### 2.6 反AI Slop规则

- 不使用紫色渐变背景
- 不使用 Emoji 作为图标
- 不使用圆角卡片+左彩色边框的组合
- 不使用 Inter/Roboto 作为主字体
- 不编造统计数据
- 每个元素必须服务于信息传达

## 三、数据来源标注规范

### 3.1 来源分级

| 级别 | 类型 | 标注格式 | 可信度 |
|------|------|----------|--------|
| A | 官方数据 | `[平台名] 官方财报/榜单` | 高 |
| B | 行业报告 | `[机构名] [报告名]` | 高 |
| C | 媒体报道 | `[媒体名] 报道` | 中 |
| D | 社区整理 | `[平台] 社区整理` | 中 |
| E | 综合估算 | `基于公开数据综合估算` | 低 |

### 3.2 必注来源

- 粉丝数、播放量 → 标注采集时间和平台
- 收入估算 → 标注为「综合估算，仅供参考」
- 排名依据 → 标注评分维度和权重
- 行业数据 → 标注原始报告名称和发布日期

### 3.3 免责声明模板

```
本报告中粉丝数、播放量、收入估算等数据来源于公开渠道和行业报告，
可能存在时效性偏差。收入数据为基于行业案例的综合估算，不代表博主实际收入。
排名综合考量了多维度指标。数据采集时间截至YYYY年MM月，仅供参考。
```

## 四、执行流程

### Step 1 · 确定分析对象
- [ ] 确定平台（B站/抖音/小红书/YouTube/公众号等）
- [ ] 确定领域（AI/科技/教育/游戏等）
- [ ] 确定排名数量（Top 10/20/50）

### Step 2 · 数据采集
- [ ] 通过 WebSearch 搜索该平台该领域的博主榜单/排名
- [ ] 搜索行业报告和媒体推荐列表
- [ ] 采集每位博主的公开数据（粉丝数、视频数等）
- [ ] 分析内容风格和盈利模式
- [ ] 记录所有数据来源

### Step 3 · 数据整理
- [ ] 按模板字段格式化数据
- [ ] 计算衍生数据（平均播放量、类别分布等）
- [ ] 标注数据来源和可信度

### Step 4 · 生成HTML报告
- [ ] 使用本模板的视觉风格规范
- [ ] 按五大板块结构组织内容
- [ ] 确保交互功能正常（展开/折叠、导航跳转）
- [ ] 浏览器验证渲染效果

### Step 5 · 交付
- [ ] 保存到 `ai-blogger-reports/` 文件夹
- [ ] 文件命名：`{平台}-{领域}-top{N}-analysis.html`
- [ ] 附带数据来源说明
